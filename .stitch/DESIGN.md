# IronTrack Design System

**DESIGN SYSTEM (REQUIRED):**
- Platform: Web, Desktop-first
- Palette: Primary Action Indigo (#6366f1), Dark Slate Canvas (#0f172a), Bento Card Surface (#1e293b), Success Emerald (#10b981)
- Styles: Glassmorphism aesthetic, bento grid layout heavily leaning on strict rectangular alignment, translucent borders (`rgba(255,255,255,0.1)`), pronounced soft shadows, and high rounding (`ROUND_EIGHT` or `16px`).
